# Telecom Customer Churn Analytics

## Project Objective

Create an end-to-end customer churn analytics solution
using MySQL, SQL, Power BI and GitHub.

## Business Problem

The organization wants to understand:

- Why customers leave
- Which customers are likely to churn
- Revenue impact of churn
- Customer retention opportunities

## Technology Stack

- MySQL
- SQL
- Power BI
- DAX
- GitHub
