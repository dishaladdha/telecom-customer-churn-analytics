# Telecom Customer Churn Analytics

## Project Overview

This project analyzes customer churn behavior in a telecommunications company using MySQL and Power BI.

The objective was to identify churn patterns, revenue impact, customer segments, and retention opportunities.

## Tools & Technologies

- MySQL
- SQL
- Power BI Desktop
- GitHub

## Project Workflow

Raw Dataset
→ Data Cleaning
→ MySQL Analytics Layer
→ Power BI Dashboard
→ Business Insights
→ Retention Recommendations

## Key Insights

- Month-to-month customers show the highest churn.
- Fiber Optic customers contribute the highest churn volume.
- Electronic Check users have the highest churn volume.
- Customers within their first year are most likely to churn.
- Churned customers represent significant revenue exposure.
