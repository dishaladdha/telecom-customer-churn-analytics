# Telecom Customer Churn Analytics

## Project Overview

This project analyzes customer churn behavior in a telecommunications company using MySQL and Power BI.

The solution helps identify:

- Churn patterns
- Revenue impact
- Customer segments
- Retention opportunities

## Tools Used

- MySQL
- SQL
- Power BI
- GitHub

## Dashboard Pages

### Executive Summary

- KPI Overview
- Contract Analysis
- Internet Service Analysis
- Payment Method Analysis

### Customer Segmentation

- Gender Analysis
- Senior Citizen Analysis
- Tenure Analysis

### Revenue Analysis

- Revenue KPIs
- Revenue Distribution
- Contract Revenue Analysis

### Retention Strategy

- High Risk Customers
- Revenue At Risk
- Retention Recommendations

## Key Insights

- Month-to-month customers show the highest churn.
- Fiber Optic customers contribute the highest churn volume.
- Electronic Check customers show higher churn behaviour.
- Customers within their first year have the highest churn volume.
- Churned customers represent significant monthly revenue exposure.
